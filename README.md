# stouter-public

Public website for [Stouter](https://github.com/dbpecka/stouter), a
lightweight service mesh for distributed clusters.

A static single page with no build step: `index.html`, `style.css`, and
`favicon.svg`.

Preview locally:

```sh
python3 -m http.server 8000
```

Deploy by serving the repository root from any static host (GitHub Pages,
Netlify, Cloudflare Pages, S3, nginx).
